# Factory passport reference scan

Retrieved on 2026-10-23 through the Internet Archive after the original file
host stopped resolving. See `provenance.json` for URLs, hash and filename mapping.
The photographs and their contents retain their original authorship. They are
reference documents, not original project documentation.

- `page-02.jpg`: technical data; some printed digits are degraded.
- `page-03.jpg`: materials and plate thicknesses.
- `appendix-01.jpg`: perspective general arrangement.
- `appendix-02.jpg`: top arrangement with numbered frame positions.
- `appendix-03.jpg`: sleeping-seat arrangement.
- `appendix-04.jpg`: windshield wiper installation.
- `appendix-05.jpg`: awning installation and connections.

The five appendices do not supply a complete dimensioned production drawing set.
Frame numbers on the plan are identifiers, not longitudinal coordinates. Do not
assume a frame spacing or treat pixel measurements as explicit factory dimensions.
See `../../DIMENSION_RESEARCH.md` for the dimensional audit.

# Owner evidence: Sarepta 691

[First-hand restoration thread](https://forum.motorka.org/threads/28515/),
PetroviCh / Sergey, first post 2020-09-22, reviewed 2026-10-23. The owner
identifies a 1976 hull and describes an owner-cut hole in the forward locker
partition as a defect. This supports retaining the original locker boundary,
not copying an open-through conversion. It does not establish the footwell
section dimensions. Text/photos remain the contributor's; no licence inferred.

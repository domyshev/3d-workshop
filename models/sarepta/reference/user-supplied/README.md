# User-supplied references and feedback

Preserved 14 available conversation attachments on 2026-10-23. `manifest.json`
maps the original attachment identifiers to stable filenames and image roles.
The first original underway photograph is no longer at its temporary path;
the repeated copy of the same photograph is preserved as
`real-boat-underway-repeat.png`. No visual reference needs to depend on that
missing temporary copy. User-uploaded does not mean user-authored. Original
photographer/illustrator identities are not established here.

Use real-boat photographs and drawing crops to assess shape. Kit images are
secondary reconstructions. Model-feedback screenshots document defects and
user intent; they are not prototype measurements.

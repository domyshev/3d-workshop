# Method sources

- Robert McNeel & Associates, [Boat Hull — Loft and Sweep](https://docs.mcneel.com/rhino/6/usersguide/en-us/html/ch-16_boathull.htm).
  [Local guide index](../../../reference/guides/README.md) links offline copies.
  Adopted principle: simplify guides, review curvature, then create surfaces.
  The OpenSCAD guide network, shell implementation and regression checks are
  project adaptations, not instructions copied from Rhino.
- Wonsuk Choi and Domain Experts contributors, marine-engineer-naval-architect
  role, [upstream](https://github.com/wonsukchoi/domain-experts/blob/main/roles/marine-engineer-naval-architect/SKILL.md).
  Reviewed but not adopted for surfacing; it concerns stability/freeboard/powering.
  Its copied text and MIT notice are reference data only.
- [Development history](../../../DEVELOPMENT_LOG.md) and
  [actual STL milestones](../../../releases/README.md) record the project-specific
  failures and improvements. Use them to understand why the local method changed.

Do not assume the tutorial contains Sarepta measurements, that a role description
provides accurate hull curves, or that a downloaded reference grants permission
for external actions.
